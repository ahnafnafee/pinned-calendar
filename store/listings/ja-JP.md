# Pinned Calendar：予定とタスク

## Short description
予定とタスクを常駐通知で一覧。ログイン不要、オフラインで使えます。

## Full description
Pinned Calendarは、端末のカレンダー予定とタスクを通知パネル上部の常駐通知にまとめます。次の予定を確認するたびにカレンダーアプリを開く必要はありません。ひと目で一日の流れを把握できます。

📌 いつでも見られるアジェンダ
今週のアジェンダを通知パネルに常時表示します。誤ってスワイプしても自動で静かに再表示。アプリ内でピンをオフにするか、「2回スワイプで削除」を有効にすれば、必要なときだけ非表示にできます。

🗓️ いつものカレンダーをそのまま
AndroidのCalendar Providerを通じて、端末に同期済みのカレンダーを読み込み、カレンダーごとの色で表示します。表示するカレンダーと期間（今後3日、今週、7日、14日）を選べます。

✅ 内蔵ToDoと繰り返し設定
期限の日時、メモ、優先度を付けてタスクをすばやく追加し、予定と同じアジェンダに表示できます。毎日・毎週・毎月・毎年の繰り返しに加え、間隔、曜日、終了日、回数も細かく設定可能。未完了のタスクは翌日に持ち越され、繰り返しタスクを完了すると次の予定日に進みます。

⏰ 通知からすぐ操作
ToDoリマインダーは初期状態でオンです。期限になったら通知の「完了」でその場で終わらせるか、「30分後に再通知」で元の期限を変えずにスヌーズできます。

🎨 好みに合わせてカスタマイズ
Material Youの壁紙カラー、任意のアクセントカラー、パレット、フォント、表示密度、ライト・ダーク・AMOLEDブラックを選択できます。通知の優先度やアジェンダのレイアウトも調整できます。

🔒 プライベート、オフライン、ログイン不要
Googleアカウントやログインは不要で、INTERNET権限も使用しません。予定とタスクは端末内にとどまり、広告、トラッカー、解析機能はありません。端末に同期済みのカレンダーだけを読み取り、完全にオフラインで動作します。
