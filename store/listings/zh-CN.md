# Pinned Calendar：日程与待办

## Short description
在常驻通知中查看日历和待办。无需登录，完全离线。

## Full description
Pinned Calendar 将手机里的日历活动和待办事项汇总到通知栏顶部的一条常驻通知中。无需反复打开日历应用，下一项安排一眼即可掌握。

📌 始终可见的日程
本周日程常驻通知栏。即使不小心划掉，应用也会安静地重新显示。真正想隐藏时，可在应用内关闭固定通知，或启用“滑动两次移除”。

🗓️ 使用你现有的日历
应用通过 Android Calendar Provider 读取手机上已经同步的日历，并保留各日历的颜色。你可以选择显示哪些日历，以及查看未来 3 天、本周、7 天或 14 天。

✅ 内置待办与重复任务
快速添加任务，并设置截止日期和时间、备注及优先级；任务会与日历活动一起显示。支持每天、每周、每月和每年重复，也可自定义间隔、星期几、结束日期和次数。未完成的任务会顺延到下一天；完成重复任务后，它会自动进入下一个计划日期。

⏰ 直接在提醒中操作
待办提醒默认开启。任务到期时，可直接点击通知中的“完成”，也可选择“推迟 30 分钟”，在不更改原截止时间的情况下于半小时后再次收到提醒。

🎨 随心定制外观
可使用 Material You 壁纸配色或自选强调色，并选择不同的调色板、字体、显示密度、浅色或深色主题以及 AMOLED 纯黑模式。通知优先级和日程布局也可调整。

🔒 私密、离线、无需登录
无需 Google 账号或登录，应用也不申请 INTERNET 权限。活动和任务始终保存在设备上，没有广告、跟踪器或分析工具。应用只读取手机上已同步的日历，并可完全离线运行。

开源项目：https://github.com/ahnafnafee/pinned-calendar
